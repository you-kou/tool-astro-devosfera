[**Aconvert**](https://www.aconvert.com/cn/) 是一个知名的**全能在线文件格式转换与轻量编辑工具平台**。网址名称中的字母 **“A”** 代表 **“All”**，意为可以转换“所有”类型的文件（All Convert）。

该网站无需下载安装任何软件，完全在浏览器内运行，且对普通用户完全免费，是处理多媒体与文档格式转换的“瑞士军刀”类工具。

### 核心功能分类

Aconvert 将处理能力按文件类型划分为了几大板块，不仅支持**格式转换**，还包含许多针对性的**小工具**：

| **文件类型**         | **主要支持的格式**                                 | **额外实用功能**                                |
| -------------------- | -------------------------------------------------- | ----------------------------------------------- |
| **PDF**              | PDF, Word, Excel, PPT, JPG, HTML 等互转            | 拆分、合并、压缩、加密、解密、旋转、锁定        |
| **文档 (Document)**  | DOC, DOCX, XLS, XLSX, PPT, PPTX, HTML, TXT, ODT 等 | 更改文档版本、批量转换                          |
| **电子书 (Ebook)**   | EPUB, MOBI, AZW3, PDF, TXT, FB2 等                 | Kindle 格式与常规电子书互转                     |
| **图像 (Image)**     | JPG, PNG, WEBP, GIF, SVG, TIFF, ICO 等             | 调整图片尺寸、裁剪、压缩、合并、旋转、添加水印  |
| **视频 (Video)**     | MP4, AVI, MKV, MOV, WMV, WEBM, FLV 等              | 剪切视频、旋转、合并、调整分辨率/码率、提取音频 |
| **音频 (Audio)**     | MP3, WAV, AAC, FLAC, OGG, M4A, WMA 等              | 音频剪切、合并、比特率/采样率调整               |
| **压缩包 (Archive)** | ZIP, 7Z, RAR, TAR, GZ 等                           | 压缩包格式互转、解压提取                        |
| **网页 (Web)**       | URL 转换为 PDF, JPG, PNG, HTML 等                  | 网页一键存为文档或长图                          |

### 主要亮点与优势

1. **跨平台与零门槛**：只要有浏览器（PC、Mac、手机、平板），打开网页即可直接使用，无需注册账号或安装插件。
2. **多源文件导入**：
   - 支持选择本地电脑/手机文件。
   - 支持直接输入 **URL 链接**转换网络文件。
   - 整合了 **Google Drive** 和 **Dropbox** 云存储服务。
3. **批量处理与多服务器**：支持一次性上传多个文件进行批量转换。当某个服务器繁忙时，还可以在顶部切换不同的服务器节点以提升速度。
4. **灵活参数设置**：在转换视频、音频和图片时，允许自定义目标码率、帧率、分辨率、采样率等高级参数，满足一定的专业需求。
5. **隐私与安全保护**：转换完成后，系统提供直接下载链接、QR 码下载以及发送到云盘的功能。文件会在服务器保存数小时后被自动安全删除。

### 使用注意事项

- **文件大小限制**：单文件最大限制通常在 **200MB - 1GB** 之间（具体取决于文件类型，如视频限制相对更大，文档相对较小）。
- **网络与速度**：由于转换在云端服务器完成，上传和下载大型文件（如高清长视频）的速度受限于个人网络带宽及服务器负载。
- **广告支持**：作为免费服务，网站页面包含少量广告，使用时注意认准真正的“选择文件”和“开始转换”按钮。
